# Репертуар Lera Rawlick

Личное приложение для iPhone с репертуаром: тексты песен, перевод под строчками, оригинальная и моя
тональность, минусовки (слушать и пересылать), ссылки на оригинал и караоке, списки «Знаю / Новые»
и концерт из трёх блоков по шесть песен. Тёмная тема. Работает без интернета.

Адрес: **https://lera-rawlick.github.io/rawlick-songs/**

## Что умеет

- **Главная** — кнопка «Добавить песню», квадраты «Песни» (Все / Знаю / Новые) и «Концерт» (блоки 1–3).
- **Песни** — по алфавиту, поиск по названию и исполнителю, красная точка — новая, зелёная — знаю.
- **Карточка песни** — о чём песня, мои заметки, «Знаю / Новая», оригинальная тональность (≈ — источники
  расходятся), мои тональности (с Артом, с Мишей), сдвиг в полутонах, кнопки «Мой минус», «Оригинал», «Караоке».
- **Мой минус** — играет mp3 прямо в приложении и пересылает файл через «Поделиться» (Telegram, WhatsApp, AirDrop);
  если вместо файла ссылка — пересылает ссылку. Ползунок «Тон» сдвигает минус на −6…+6 полутонов без смены
  темпа (как на x-minus), прямо во время игры; сдвиг запоминается. При сдвиге 0 играет обычный плеер,
  при другом — Web Audio + SoundTouchJS (`vendor/soundtouch.js`, LGPL-2.1, лицензия рядом).
  «Переслать» отправляет исходный файл, без сдвига.
- **Текст** — припев оранжевый с полоской, куплеты обычным шрифтом, подсказки произношения из скобок — мелко,
  служебные пометки (тайминги, «2 раза», техника) — серым. Нажатие на строфу показывает и прячет перевод под ней,
  переключатель «Перевод» — у всего текста. Для песен, где я пою по транскрипции, есть переключатель «Оригинал».
- **Концерт** — 3 блока по 6 песен, внутри песни кнопки «Предыдущая / Следующая».
- **Добавить / изменить песню** — название, исполнитель, тональности, минус (файл или ссылка), ссылки,
  текст, перевод; при изменении ещё заметки, оригинал текста и место в концерте (занятое место меняется местами).
- **Удалить песню** — в карточке или в «Изменить песню», в два нажатия. Песня из каталога прячется и
  возвращается в «Тексты и минусовки» → «Удалённые песни»; добавленная в приложении удаляется совсем.

## Установка на iPhone

1. Открыть адрес выше в **Safari**.
2. «Поделиться» → «На экран Домой» → «Добавить».
3. Запускать с иконки «Репертуар».

## Тексты и минусовки — по паролю

Тексты и mp3 чужие, поэтому на сайте они лежат только **зашифрованными** (AES-GCM, ключ из пароля):
посторонний видит в репозитории лишь шифр.

1. В приложении: Главная → «Тексты и минусовки» → ввести пароль (один раз).
2. Тексты появляются сразу; минус скачивается и расшифровывается, когда первый раз нажимаешь «Мой минус».
   Перед концертом — «Скачать все минусовки» (≈200 МБ), тогда всё работает без интернета.
3. Расшифрованное хранится только в телефоне. Новые версии текстов с сайта подтягиваются сами при запуске.

Пароль лежит в `.pack-password` на Маке (в git не попадает). Обновить тексты или минусовки на сайте:

```bash
node tools/pack.js
```

Скрипт берёт `~/Desktop/Песни/Новая.txt` и mp3 оттуда же, шифрует новое в `data/`; потом коммит и пуш.
Если пароль потерян — удалить `data/` целиком и запустить снова (будет новый пароль, ввести его в телефоне заново).

Запасной путь без пароля: «Тексты и минусовки» → «Загрузить свои файлы вручную» → `Новая.txt` и mp3 из
iCloud Drive/«Песни». Текст любой песни можно вставить из «Заметок» в «Изменить песню» → «Текст»
(♥️ — куплет, 😈 — припев). После больших правок — «Сохранить копию» (JSON без mp3).

## Перевод

Кнопка «Перевести» в песне: строчки переводятся машинным переводчиком (Google, запасной — MyMemory)
и запоминаются в телефоне. Если песня записана транскрипцией, переводится раздел «Оригинал» и показывается
отдельным блоком. Свой перевод из «Изменить песню» важнее машинного.

Как приложение читает заметку: песня начинается со строки-названия (поле `at` в `songs.js`),
♥️ / ❤️ — начало куплета, 😈 — начало припева, разделы «Перевод» и «Оригинал» — слои под текстом,
абзацы со списками и рассказом о песне в начале или в конце — «Мои заметки».
Повторная загрузка заметки обновляет тексты, но не трогает то, что исправлено в приложении.

## Устройство

Статический сайт без сборки и зависимостей.

| Файл | Что внутри |
|---|---|
| `index.html` | разметка и стили |
| `app.js` | экраны, навигация (`#адрес`), хранилище IndexedDB, плеер, «Поделиться», загрузка файлов |
| `core.js` | чистая логика: тональности, разбор заметки, строфы, привязка минусовок |
| `songs.js` | каталог песен: тональности, описания, ссылки, имена файлов минусовок |
| `sw.js`, `manifest.webmanifest`, `icon*.png` | работа без интернета и иконка на экране «Домой» |
| `tools/pack.js` | шифрует тексты и минусовки в `data/` (`meta.json` — соль и версия, `texts.bin`, `m/*.bin`) |
| `test/core.test.js` | тесты логики |

Новая песня в каталог для всех устройств — запись в `songs.js` (поля описаны в начале файла).
Песни, добавленные в самом приложении, живут только в телефоне.

## Разработка

```bash
python3 -m http.server 3011 --bind 127.0.0.1
```

```bash
node --test
```

Тесты разбора берут настоящую заметку и mp3 из `~/Desktop/Песни` (или из папки в `SONGS_DIR`);
без неё эти тесты пропускаются.

Публикация: пуш в `main` → GitHub Pages обновляет сайт сам. При изменении файлов приложения
поменять `VERSION` в `sw.js`, чтобы телефон сбросил старый кэш.

## Известные ограничения

- Данные хранятся в Safari на телефоне: если очистить данные сайтов, отметки и тексты пропадут.
  Поэтому есть «Сохранить копию»; mp3 загружаются заново из iCloud Drive.
- Разбор заметки эвристический: у части песен заметки могут попасть в текст или наоборот —
  исправляется в «Изменить песню».
- Переводов в заметке почти нет; машинный перевод — дословный, не литературный, и нужен интернет в момент перевода.
- Переводчик Google без ключа — неофициальный адрес; если перестанет отвечать, сработает MyMemory (лимит ~5000 знаков в день).
